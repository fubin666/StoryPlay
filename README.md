# StoryPlay | 短剧剧本生成平台API
> 面向短剧制作方、内容平台、剧本工作室的企业级剧本生成工具，覆盖原创剧本创作、爆款改写、网文IP改编、爆款榜单、剧本质量评估全场景，支持国内与海外短剧剧本产能规模化落地

官网链接：https://storyplay.cn/

## 核心能力优势
### 适配国内和海外剧本
基于专业故事创作理论与剧作算法模型打造，支持国内、欧美、日韩多市场剧本创作。

### 核心需求全覆盖
覆盖原创生成、爆款改写、IP改编、榜单分析、质量评估五大短剧生产核心场景。

### 无缝嵌入企业工作流
标准化API接口，可接入企业内外部内容生产流程，规模化提升剧本产能。

## 五大核心功能
### 1. 原创短剧剧本生成
从零全链路孵化短剧剧本，适配国内与海外创作逻辑。
- 灵感主题策划
- 人物小传设定
- 故事大纲创作
- 分集集纲生成
- 剧本正文批量生成

### 2. 对标爆款剧本改写
结构化拆解对标爆款，定向优化改写二次创作。
- 爆款剧本深度解析
- 改写方向灵感策划
- 人物设定重塑优化
- 分集结构重构调整
- 改写正文批量生成

### 3. 网文IP短剧改编
一键拆解网文IP，快速产出可落地的改编初稿，压缩IP改编周期。
- 网文章纲智能拆解
- 核心故事梗概提炼
- 角色人设体系提炼
- 改编故事大纲输出
- 分集集纲批量生成
- 改编正文批量产出

### 4. 爆款榜单
同步国内外平台爆款榜单，洞察题材热度与创作风向。
- 本周榜单分布
- 创作方向建议
- 爆款剧作

### 5. 剧本初筛质量评估
国内+海外双市场评估体系，为立项、采购、出海发行提供数据支撑。
- **国内市场**：多维度剧本质量量化打分 + 内容合规风险提示
- **海外市场**：目标区域文化适配度评估 + 本地化调整建议
